# Pre-flight checklist

Before starting a new `capabilities_*` file:

- [ ] `lint-arwaky-cli scan <layer-path>` exits 0 on the current feature folder.
- [ ] The relevant language HOW-TO's `Verify` block was executed and is clean.
- [ ] The file will be registered in `__init__.py` / `mod.rs` / `index.ts`.
- [ ] Language fallback compile is clean if the HOW-TO lists it.
- [ ] The feature folder carries `FRD.md` and `BACKLOG.md` (AES702).
